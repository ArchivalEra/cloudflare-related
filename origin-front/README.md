## 已消化的对方回条（A–E）与修正前提

* **A 超时**：无 P99（tracing 无 span，采样 n=3）；冷拉 3GB~3min 是“远端限速 × 本机争抢”不是带宽（管子可到 2Gbps）；Range 5MB 段秒级。→ 02 取值与 idle 硬约束据此定。
* **B XFF**：不可测（无日志）→ 00 先行；段位 TODO（腾讯控制台）；直连先挡归安全组（7777 公网可达是事实）。
* **C 观测**：tracing 现成；prom 未接 → 01 是前置任务不是加几行；healthz 不动。
* **D 限流**：零限制现状确认；IP cap 归代码，直连归运维，运维通路永不挡。
* **E 版本**：0.8.1 + rustls，方案有效。
* **§5 前提修正**：磁盘 580MB/s（≈4.6Gbps）本就跑满 2Gbps 上限，字节路径 RAM tier 更无账算；placement (1) 列表缓存不受影响。
